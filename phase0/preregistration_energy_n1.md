## 1. 命题（一句话，锁定）

美国炼厂开工率（EIA WPSR Table 2「Percent Utilization」，美国总量，周度）**系统性领先** VanEck Oil Refiners ETF（CRAK）的周收益率 **4–13 周**；方向为正：开工率上行后，CRAK 后续 4–13 周的周收益倾向为正。

> 标的锁定为 CRAK 单一标的。用户原话中的「CRAK 等」不构成事后可替换的标的池；换标的 = 改参，必须登记并计次。

## 2. 传导逻辑（为什么值得一测）

炼厂开工率是成品油供给的慢变量：开工率上行通常先于炼厂利润与炼油商现金流改善，再到股价定价。若该慢变量对 CRAK 存在 4–13 周的领先关系，应表现为正相关峰值落在该窗口；若峰值不在窗口、方向为负或效应量落在弱关联带，则本命题不成立。本稿只验证「领先—滞后关联」，不声称因果。

## 3. 数据口径（锁定）

| 项 | 锁定口径 |
|---|---|
| 领先面 | EIA Weekly Petroleum Status Report（WPSR）Table 2，行 `Refiner Inputs and Utilization → Percent Utilization`，美国总量；周度；单位百分比；不季调。报告周结束日为周五。 |
| 领先面取数 | 主路径：EIA WPSR 周报归档页的 `download/table2.csv`，逐周读取；最新一周用 `https://ir.eia.gov/wpsr/table2.csv`。CSV 表头第一列是报告周结束日（如 `10/30/26`），按表头日期入库，不按归档页 URL 日期入库。 |
| 领先面不用的路径 | EIA API v2 `petroleum/pri/wcrr` 需要免费 API key；本稿不依赖。FRED `WCRR` CSV 在本机网络下超时/返回非数据内容，未采用。Stooq 按作者指示不使用。 |
| 滞后面 | Yahoo chart API，符号 `CRAK`（VanEck Oil Refiners ETF），日线 `adjclose`；美元；交易所时区 `America/New_York`。 |
| 周收益率 | `r_t = adjclose_t / adjclose_{t-1} - 1`，按周最后一个交易日计算，周标签固定为该周周五；若周五休市，用该周最后一个交易日，标签仍为周五。 |
| 样本窗口 | 日历窗口 `2016-11-07`–`2026-10-30`；首个周标签 `2016-11-11`，末个周标签 `2026-10-30`。Yahoo 10 年日线可取到 `2026-11-06`，但 WPSR 最新已发布周为 `2026-10-30`；预注册只纳入开跑前已发布数据，故末日取 `2026-10-30`。 |
| 对齐 | 领先面与滞后面一律按周标签对齐；不把 WPSR 的发布日期当作数据日期。WPSR 周报通常在周结束后的下一周周三发布，因此 `k=0` 为同周共动/前视诊断，不参与判定；`k>=1` 才视为可交易滞后。 |
| 标准化 | 两面分别做滚动 52 周 z-score：`z_t = (x_t - mean(x_{t-51..t})) / std(x_{t-51..t})`，`min_periods=26`；只用当期及过去 52 周，不使用未来值。 |
| 缺失处理 | 不插值、不前向填充。某周缺失则丢弃该周并在运行记录中报数；有效周缺失超过 5% 时停止并记为数据失败，不产生判定。 |
| 指标数量 | 只保留周收益率一个指标；不使用成交量、成交额或第二标的。滞后位共 14 个（`k=0..13`）。 |

## 5. 判定标准（锁定，跑之前写死）

对 `k = 0..13` 计算 Pearson 相关 `corr(lead_z_t, lag_z_{t+k})`，按周标签配对，pairwise complete；每个 `k` 都打印样本量 `n`。判定只看 `pass_window = [4,13]` 内的最大正相关 `peak_corr` 及其位置 `peak_k`。

| 参数 | 锁定值 | 说明 |
|---|---|---|
| `lag_range` | `[0,13]` | 共 14 个滞后位；`k=0..3` 只打印，不参与通过判定 |
| `pass_window` | `[4,13]` | 用户指定的领先窗口 |
| `pass_corr` | `0.3` | 沿用项目既有判定线；高于既有零分布 p99（9/27 滞后位校准为 0.218–0.248） |
| `noise_band` | `0.19` | 弱关联描述带，不等于通过线 |
| 方向 | 正 | 领先面上行 → 滞后面上行 |
| 指标 | 周收益率 | 只看一个指标，避免多指标挑结果 |
| 多重比较 | 14 滞后 × 1 指标 | `0.3` 为经验性补偿；本稿不重跑零分布，避免开跑前动线 |

**三种结果定义**

| 结果 | 条件 |
|---|---|
| 成立 | `peak_k` 落在 `[4,13]`，`peak_corr >= 0.3`，且为正相关 |
| 灰区 | 峰值在 `[4,13]` 内但 `0.19 <= peak_corr < 0.3`；或峰值在窗口外但 `|peak_corr| >= 0.19` |
| 不成立 | 验证段 `[4,13]` 内最大正相关 `< 0.19`；或验证段 `[4,13]` 内最大相关为负；或验证段成立但留出段未通过 |

**什么算不成立（逐条写死）**

1. 验证段 `[4,13]` 内最大正相关 `< 0.19`。
2. 验证段 `[4,13]` 内最大相关为负。
3. 验证段判为成立，但留出段按同一标准未通过。
4. 数据缺失超过 5%，或口径不可复现，导致无法产出有效配对；记为数据失败，不得写成成立。

> 「不成立」只表示在该样本、该口径、该窗口下未观察到预期方向与效应量；它不是对因果关系的终局否定。统计显著性不作为通过标准，只看效应量与峰值位置。

## 6. 训练 / 验证 / 留出的职责与闸门

| 段 | 允许做什么 | 禁止做什么 |
|---|---|---|
| 训练 | 检查数据对齐、缺失、z-score 行为；可算相关做诊断 | 不得根据训练段结果改窗口、阈值、指标、标的、样本切分 |
| 验证 | 第一次正式判定 | 不得因未通过而改参后重跑并选用更好结果 |
| 留出 | 验证成立后开封一次确认 | 不得二次开封；不得用留出段结果反向调参 |

闸门顺序：训练段自检 → 验证段判定 → 仅当验证段「成立」才开封留出段 → 留出段确认。任何一步失败，后续步骤不启动。
