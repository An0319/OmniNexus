## 0. 为什么开 v2：结构缺陷，不是结果不好看

v1 对阴性对照的规则是「两段各自按 `α = 5%` 判显著，两段都不许显著才算通过」。
两段各做一次 5% 检验，族错误率是 `1 - 0.95² = 9.75%`，**这是跑之前就能算出的算术**，
与数据、与阴性 A 那次 3.9%/3.0% 的边缘命中都无关。也就是说：v1 在「两个阴性段都干净」
这件事上本来就只给了约 90% 的保证，出现一次边缘命中是规则写得不够严的正常结果，
不是尺子失控。v2 的改动方向也因此是**更严**，不是为结果调松紧：

1. **多重比较校正（本段 α = 2.5%）**：两段合计族错误率回到 `1 - 0.975² ≈ 4.94%`，
   与 v1 宣称的「5% 显著性」对齐。每段的显著性判据同时要求全平移与远平移两版零分布
   `P(null ≥ 峰值)` 都 ≤ 2.5%，且峰值块自助 95% 区间不含 0。
2. **两段同向一致（附加条件）**：同一个对照里，两段都必须显著，且两段的峰值符号相同。
   对阴性对照而言这是额外一道闸（两段必须同时在同一方向越线才算「测得出」）；
   对阳性对照而言它替代 v1 里「另一段不得出现反向显著峰」的写法，两种说法等价但更直白。

v1 的其余判据（阳性峰值须落在先验带 `k∈[2,6]`、只看 P 与区间不看点值）原样继承。
v2 结果只作探索性重读，不改变 v1 的原始结论。

## 1. 第三阴性对照（跑前固定）

加一对新标的，选标准在跑前写死，四条同时满足：

1. 板块级 ETF（不是个股，避免公司特有事件）；
2. 两者无直接上下游或同一成本链（不经过原油—成品油、也不经过医疗—钢铁）；
3. 公开可得、有 ≥ 20 年周频历史（每段 ≥ 10 年，避免再用 `n≈92` 量级的段）；
4. 与已用符号（WTI、GASREGW、XLV、SLX）不重复。

选定与固定参数：

| 项 | 第三阴性 |
|---|---|
| 领先序列 | XLB（材料板块）周收益率 |
| 滞后序列 | XLP（日常消费板块）周收益率 |
| 滞后范围 / 窗口 | `k = 0..8` / `[1,8]`（与既有对照完全一致） |
| 分段 A | `1999-01-01 .. 2012-12-28` |
| 分段 B | `2013-01-04 .. 2026-10-30` |
| 零分布 / 区间 | 全平移 + 远平移 `dist>=26`；块自助 `2τ`、5000 次、`seed=20261107` |

选 XLB/XLP 的理由只涉及机制与可得性：材料与日用消费之间没有可言的定价传导链，
两条都是 1998-12 上市的板块 ETF（分段按中点切，不是按结果切）。
**若抓不到或历史不足，明说并停在这一步，不换标的凑数。**

## 2. 功效曲线（注入式模拟）

### 2.1 要回答什么

「没看见」要能翻译成「排除了多大」。用同一条处理链、同一把尺子，把已知强度的相关
注入真实周序列，统计检出率，得到 `80%` 与 `50%` 检出率对应的最小 `r`。

### 2.2 注入方式

- 领先序列取真实 WTI 原油周收益率的连续块（保留其边际与自相关），长度满足
  `n_train + n_valid + k0 + 52 周滚动窗 + 余量`。
- 噪声取真实零售汽油周收益率的**远平移**（圆周距离 ≥ 26 周）后的同长片段，
  同样保留边际与自相关；远平移保证它与领先序列在目标滞后上无关。
- 注入在收益率尺度上做线性混合，目标滞后固定为 `k0 = 3`（落在窗口 `[1,8]`
  与阳性先验带 `[2,6]` 之内，跑前固定）：

  `lag_inj[t] = r * lead[t - k0] + sqrt(1 - r^2) * noise[t] * (sd_lead / sd_noise)`

- 已知局限（必须写明）：混合后序列的边际不再逐点等于原汽油收益率，而是两条近似
  正态序列的线性组合；之所以不用「按分位重排」来精确复制边际，是因为重排会打乱
  时间顺序，把零分布赖以成立的序列自相关一并毁掉。因此本曲线是**近似但自洽**的
  注入式模拟，不是解析近似；报出时同时给出注入名义 `r` 与实测 `k0` 相关（取各次
  重复的中位数），两者接近才说明注入生效。
- 每段 z 化仍由 `ruler.measure` 内部按发布链做（52 周滚动 z，`min_periods=26`）。

**实现前的一处成本调整（在任何正式模拟之前写下，不涉及统计改动）**：两段各自独立取
真实块并各自带 52 周预热，而不是把两段拼成一条长序列再切。原因：循环平移零分布的
平移量是 `L-1`，拼成长序列会让每段都背上另一段的长度（一次模拟的平移次数从约 540
涨到约 940），而每段的 `n`、零分布构造与判定完全不变。代价是两段不再共享同一段历史，
对「单段检出率」与「两段同向一致」的口径没有影响。噪声的圆周平移量取各块长的一半
（块长 ≥ 220 时 `dist ≥ 110 ≥ 26`，满足远平移定义）。

### 2.3 网格与重复

| 项 | 固定值 |
|---|---|
| `r` 网格 | `0.10, 0.15, 0.20, 0.25, 0.30, 0.35, 0.40, 0.45, 0.50`（9 点，步长 0.05） |
| 每格重复 | 60 次 |
| 随机种子 | 每格 `seed = 20261107 + 1000 * round(r*100)`，与 `ruler` 默认块自助种子分离 |
| 模拟段长 | 训练段 `n ≈ 285`、验证段 `n ≈ 92`（对齐批次一临床两段的量级） |
| 判定 | v2 单段判据：全/远 `P(≥峰值) ≤ 2.5%` 且区间不含 0 |

**判定口径的一处结构性修正（正式网格开跑前写下，理由是算术而非结果）**：模拟段只有
`n≈285/92`，循环平移总数随之只有约 350/170 个，其中 `dist<26` 的近平移（`s=1..13`）
占比约 `13/350 ≈ 3.7%` 与 `13/170 ≈ 7.6%`。注入发生在 `k0=3` 时，近平移 `s=1,2,3`
本就会保留大部分对齐，因此「全平移版 `P ≤ 2.5%`」在这些短序列上**结构上无法达到**
（分母里天然含 3.7% 的近平移保留），这不是尺子的问题，是短序列模拟的伪影。
真实对照的序列长度是 1450–2129 周，近平移占比 < 1%，全平移版才有意义（阳性实测
`7/2127`）。故功效曲线以**远平移口径**（`dist>=26`，`P ≤ 2.5%` 且区间不含 0）为主，
同时并列记录严格双版口径的检出率，供对照。v2 的正式判定（真实序列）仍是全+远双版。

### 2.4 报告的三个数

- `n≈92`（验证量级）的 `80%` 与 `50%` 检出线 `r`；
- `n≈285`（训练量级）的 `80%` 与 `50%` 检出线 `r`；
- 附：两段同向一致的合并检出率（v2 完整规则下的实际检出率），作为旁注。

检出线由 9 点网格**线性内插**，网格内无交点则报「> 0.50 或 < 0.10，网格外」，
不外推。这是模拟结果，不是解析近似。

### 2.5 用途（写进结果里）

若 `n≈92` 的 80% 检出线为 `r*`，则今天临床验证段的 `0.2035` 只能表述为
「本批看不见、且不排除任何 `< r*` 的真实关系」，不能写成「不存在」。若检出线低于
`0.2035`，则「测不出」本身变成一个值得追的信号。这一步做完，今天的否定结论才有边界。

## 5. 跑后登记：一处实现修正（不改判定口径）

按「方法描述必须与代码一致」的约定改代码、不改判定：

- 不变：`r` 网格、`k0=3`、窗口 `[1,8]`、每格 60 次、v2 每段 2.5% 判据、远平移主口径；
- 首轮产物作废（本地留存 `power_raw_firstrun_invalid.jsonl`，不入库），不计尝试次数。
