# 阶段二 · 尺子对照实验设计（探索性，非预注册）

> 性质：**探索性沙箱**。不预注册、不进过程账本、不计尝试次数、不进任何对外报告；
> 不碰临床账与留出段，不碰 `phase0/batch1_report.md/.html` 与两份预注册稿的锁定条款。
> 本文件在任何数据抓取与任何计算之前写定；跑完若需改动，只能新开一版并写明改了什么、为什么。

## 1. 问题与通过判据

今天两本账都是否定结果。一把从未称过已知重量的秤，读 0 说明不了任何事。
本实验用**同一把尺子**（`phase0/ruler.py`）测一对**机制上必然有领先关系**的序列与一对
**产业链上无关**的序列：

| 结果 | 说明 | 下一步 |
|---|---|---|
| 阳性也测不出 | 尺子太严或统计量选错 | 先修尺子，换数据毫无意义 |
| 阳性测得出、阴性测不出 | 尺子可信 | 今天的否定结果成立，可以往下做能力 |
| 两个都测得出 | 假阳性率失控 | 判据重做 |

## 2. 固定参数（跑之前定死，跑完不改）

两对序列共用同一处理链（`run_batch1.py`：周五标签 → 周频 → 52 周滚动 z，
`min_periods=26` → 段内配对 `t <= end-k` → 交叉相关），共用同一条尺子（`ruler.measure`）。

| 项 | 阳性对照 | 阴性对照 |
|---|---|---|
| 领先序列 | WTI 原油周收益率 | 医疗板块 XLV 周收益率 |
| 滞后序列 | 美国常规零售汽油周收益率 | 钢铁板块 SLX 周收益率 |
| 滞后范围 | `k = 0..8` | `k = 0..8` |
| 搜索窗口 | `[1,8]`（含） | `[1,8]`（含） |
| 先验滞后带 | `[2,6]`（原油成本向零售价的传导通常 2–6 周） | 不设 |
| 分段 A | `1992-01-03 .. 2010-12-31` | `2006-11-03 .. 2015-12-25` |
| 分段 B | `2011-01-07 .. 2026-10-30` | `2016-01-01 .. 2026-10-30` |
| 零分布 | 循环平移穷举：全平移 `s=1..L-1`；远平移 `dist>=26` | 同左 |
| 区间 | 块自助（块长 `2τ`，5000 次，`seed=20261107`） | 同左 |

`k=0` 只作为处理链的一格被计算，判定窗口从 `k=1` 起，避免同期市场因子把阴性对照污染。

**通过判据**

- 阳性通过 = 某一段的窗口峰值满足全部三条：① 落在先验带 `k∈[2,6]`；② 全平移与远平移的
  `P(null ≥ 峰值)` 都 ≤ 5%；③ 峰值相关的块自助 95% 区间不含 0。且另一段不出现反向显著峰值。
- 阴性通过 = 两段的窗口峰值都不满足显著（`P(null ≥ 峰值)` 全/远均 > 5%，或区间含 0）。
- 只看 `P` 与区间，不看点值大小；`0.19` / `0.30` 不参与本次判据（它们是批次一的固定线，
  本文不改也不引用为通过线）。

**不许调参**：滞后范围、窗口、分段、判定阈值已在上面写死。跑完若想改，只能另开
`control_design_v2.md` 并写清改动与理由，本次结果保留。

## 3. 数据来源与留痕

| 序列 | 来源 | 端点 | 频率 | 预期可用长度 |
|---|---|---|---|---|
| WTI 原油 | FRED `DCOILWTICO`（Cushing WTI 现货，日） | `https://fred.stlouisfed.org/graph/fredgraph.csv?id=DCOILWTICO` | 日 → 周（周五取最后） | 1986 起 |
| 零售汽油 | FRED `GASREGW`（美国常规零售汽油价，周） | `https://fred.stlouisfed.org/graph/fredgraph.csv?id=GASREGW` | 周（周一）→ 周五标签 | 1990-08 起 |
| XLV | Yahoo chart API `XLV` 日线 `adjclose` | `https://query1.finance.yahoo.com/v8/finance/chart/XLV` | 日 → 周 | 1998 起 |
| SLX | Yahoo chart API `SLX` 日线 `adjclose` | 同上 | 日 → 周 | 2006 起 |

留痕要求：原始文件存 `phase0/controls/data/`，快照注记写 `snapshot.json`（每条含抓取时刻
`fetched_at_utc`、URL、行数、首末日期、文件 SHA256）。同一份数据抓取两次逐值比对；
不一致时在结果文件里写明哪一条、差在哪。

抓不到就明说并给替代方案，不用近似序列冒充。

**数据可用性回填（测量前、未看任何结果时据实修正）**：SLX 首个周标签为 `2006-10-27`
（ETF 上市晚于原设想的 2006-02），因此阴性对照的分段 A 起点改为 `2006-11-03`，
长度约 9.2 年；其余参数未动。阳性对照的分段起点 `1992-01-03` 在 GASREGW 与
DCOILWTICO 的可用范围内，保持不变。

二次抓取比对：FRED 两份字节级一致；Yahoo 两份在部分行末位有 `1e-5` 量级的浮点抖动
（相对于百元价位约 `1e-7` 相对量），不是数据修订，`snapshot.json` 逐条记录差异行数与最大绝对差。

## 4. 输出

`phase0/controls/run_controls.py` 用 `ruler.measure` 各跑一次，结果落
`phase0/controls/control_results.md`：每段给出峰值（值、k、n）、全/远平移的 `P(≥峰值)`、
段内 p70 / p95 等效阈值、`N_eff`、峰值块自助区间，以及三条判据的落点。
