## 5. 判读

- 阳性两段均在 k=2 通过三条判据：全平移 P(≥峰值) 7/2127（0.3%）、远平移 0/2077；峰值区间 A `+0.318…+0.410`、B `+0.362…+0.485`，均不含 0；峰值量级 0.37 / 0.43，落在先验带 2–6 周内。
- 阴性段 B 测不出：峰值 `+0.0358 @ k=7`，P(≥峰值) 85%，区间 `-0.044…+0.112` 含 0。
- 阴性段 A 是边缘越线：峰值 `+0.1268 @ k=8`，恰在段 p95=0.12 之上，全平移 57/1451（3.9%）、远平移 42/1401（3.0%），区间 `+0.024…+0.228` 不含 0。
- 按跑前写死的判据（阴性两段都不许显著），结果落在第三行「两个都测得出」。但成因更像一次边缘假阳性：两段阴性只有一段以 3–4% 越线，5% 线在两段上做两次检验的族错误率约 10%，且该峰值只比段 p95 高 0.007。判据 v2 只能在明写理由后另开（候选：按段数做族错误率校正，每段 2.5%；或要求两段同向一致），v2 结果仍只当探索性读。
- 这些 P 是「零分布里达到或超过该峰值的平移占比」，不是抽样 p 值。

## 6. 判据 v2（2026-11-07 追加，v1 原文保留）

### 6.1 判据原文

> **v2 阳性通过**：两段的窗口峰值都落在先验带 `k∈[2,6]`，两段都满足「全平移与远平移 `P(null ≥ 峰值)` 均 `≤ 2.5%`，且峰值块自助 95% 区间不含 0」，且两段峰值符号相同。
>
> **v2 阴性通过**：两段都不满足上述单段显著（任一条不满足即算不显著）。「测得出」需要两段同向且都达到 2.5%。
>
> **为什么每段 2.5%**：v1 两段各按 5%，族错误率 `1-0.95²=9.75%`；v2 取 `2.5%` 后族错误率 `1-0.975²≈4.94%`。这个算术在跑之前就成立，与阴性 A 那次边缘命中无关；v2 是**方向更严**的修正，不是看结果后调松紧。
>
> **两段同向一致**作为附加条件同时保留：阳性要求两段都显著且同向；阴性要求两段都未达显著（因此也不可能构成「同向测得出」）。

## 7. 功效曲线（2026-11-07 追加）

### 7.1 口径

- **注入式模拟，不是解析近似**：领先序列取真实 WTI 原油周收益率连续块，噪声取真实
  零售汽油周收益率圆周远平移（距离 ≥ 26 周）后的同长片段，按 `lag = r·lead[t-3] + sqrt(1-r²)·noise·(sd_lead/sd_noise)` 混合；注入滞后 `k0 = 3`（窗口 `[1,8]` 与先验带 `[2,6]` 之内）。
- 每段仍走同一处理链与同一把尺子（`ruler.measure`：52 周滚动 z、段内配对、循环平移零分布、块自助 95% 区间），判定按 v2 每段 `2.5%`。
- 模拟段量级对齐批次一：段跨度取 296/104 周，峰值处的实际配对行数约 `n≈293` / `n≈101`（批次一在 `k=11/13` 处是 `285/91`，同量级）；`r` 网格 `0.10..0.50` 步长 `0.05`，每格 `60` 次重复。
- 两种口径并列：主口径按跑前写定的远平移（7.3 前三组数）；同时列出 v2 部署判据的严格双版（全+远同时 `≤ 2.5%`）。设计 §2.3 曾在开跑前判断「全平移版在短块上结构上不可达」（当时单块实测 `13/363 ≈ 3.6%`）；全网格跑完后该判断不成立——随机化块起点后，部分实现的 `p_all` 可 `≤ 2.5%`，训练段严格双版检出率与远平移版几乎相同，验证段约为其一半。真实对照序列长 1450–2129 周，近平移占比 < 1%，部署口径在真实数据上更接近远平移版。
- 每次重复是一个独立实现：领先块起点在可用历史内随机、汽油噪声的圆周平移量随机（均落在 `dist ≥ 26` 的远平移区），二者随 `(r, rep)` 变化。首轮实现把这两样都固定、只换自助种子，60 次重复实为同一实现（检出率退化成 0/100 阶跃），作废并修正后重跑；这是实现与「60 次重复」口径不符的修正，不涉及判定条件。
- 每格 `60` 次重复，检出率的二项标准误最大约 ±6.5 个百分点；检出线由 9 点网格线性内插，网格外交代的就地注明，不外推。

### 7.4 用途与边界

今天临床验证段峰值为 `0.2035`（批次一固定线，未重算、未改动）。把本曲线的验证段检出线与它并排：远平移 80% 线 `0.4045`、50% 线 `0.2778`；严格双版 80% 线 `网格外（高于 0.50）`、50% 线 `0.4083`。`0.2035` 低于全部四条线：本批「看不见」能翻译出的排除上限很弱——在本批尺寸下，`0.20` 量级的真实关系被检出的概率不到五成（7.2 表 `r=0.20` 一行可读具体值）。因此未检出既不等价于 `0.2035` 不存在，也不足以排除它；要把「排除 ≥ r」说成强结论，`r` 至少要到上述 80% 线。

本条只给模拟边界，不改批次一的判定线，也不把否定结论升级成「不存在」。

### 7.5 局限（必须与数字一起读）

- 混合后序列的边际不再逐点等于原汽油收益率（两条近似正态序列的线性组合）；不用分位重排是因为重排会毁掉零分布赖以成立的序列自相关。曲线是**近似但自洽**的注入式模拟。
- 模拟块短，全/远两版的差别在本网格里比开跑前的预估小（见 7.1）：严格双版的代价主要落在验证段（检出率约为远平移版的一半），真实长序列上这一差距会进一步缩小。
- 每格 `60` 次重复，曲线在两条相邻网格点之间可能有 ±6.5 个百分点量级的抖动；检出线用线性内插，不宣称精度高于网格步长 `0.05`。
- 逐次重复的原始记录 `power_raw.jsonl` 仅本地留存，不作为对外证据；仓库内保留 `power_summary.json` 与本脚本。

## 8. 三条路的代价对照（2026-11-08 追加）

问句：**要把 `0.2` 量级的关系变成可判，代价是多少。** 本轮只做测算，不改任何已有口径、不碰临床账与留出段、不动已发布报告；跑前设计见 `paths_design.md`（含 §2.1 与 §2.2 两处开跑前修正）。

### 8.1 三条路的口径

- **换频率**：把同一对序列（WTI 原油 → 美国零售汽油）换成日频，仍走 `ruler.measure`、同一注入公式（`run_power._one_block`）、同一 `k0 = 3`、同一窗口 `[1,8]`、同一 v2 每段 `2.5%`。**常数按「观测行数」而非周单位映射**（`k0=3 行`、预热 `52 行`、`far_min=26 行`），因为 `seg_xcorr` 的移位按行、裁剪按周，周单位映射在日频上不同义（见 `paths_design.md` §2.1）。
- **缩命题**：不需要新数据。给定段长与功效曲线，把「没检出」翻译成「可排除 ≥ r」的上限。
- **重排切分**：总跨度固定为 400 周（现状 296+104），只改两段比例，重算每段的注入式检出线。

每格重复次数：重排切分 `20` 次（`baseline valid` 一段因首轮参数不同为 `20–30` 次），日频 `8` 次。二项标准误在 `80%` 处分别约 `±8.9` / `±14` 个百分点。

### 8.4 自相关到底吃掉了多少（本轮的实测反例）

「日频样本看着多，但自相关会吃掉大部分」这个预期在本项上**没有兑现**，原因在于被吃掉的部分发生在「滚动 z 的平滑」上，而两种频率的平滑都约等于一个窗口：

- 零分布的有效独立量 `neff_far`：周频 104 周段 `15.2`（121 个远平移 / `τ≈8.0` 周），日频 520 交易日段 `76.5`（537 个远平移 / `τ≈7.0` 交易日）。
- 名义样本比 `506/100 ≈ 5.0`，有效独立量比 `76.5/15.2 ≈ 5.0` —— **两者一致，增益基本没被吃掉**。
- 收益率本身的自相关确实很低：日频配对乘积的 `τ≈1.0`，`neff_obs` 约 `355–478`（名义 `506`）；周频 `τ≈1.0`，`neff_obs` 约 `94–99`（名义 `100`）。

也就是说，日频换来的是「约 5 倍的独立平移量」，代价不在信息量，而在**口径**：滞后窗语义从「周」变成「交易日」。

### 8.5 判断（按要求给结论）

**先走路径一（换频率），理由三条。**

1. 它是三条路里唯一把 80% 线压到 `0.2` 量级的：`0.40 → 0.21`。`0.2` 由此从「不到五成把握」变成「约八成把握」，是真的跨过了判定边界，而不是仅仅缩小网格。
2. 它不需要更长的历史：同一 104 周日历跨度就够（约 2 年日频），而现有日频历史约 18 年（交集 4630 行），样本不是瓶颈。
3. 数据层面已实测（8.2），不是「应该有」；且不需要改任何已发布口径——尺子、注入公式、`k0`、窗口、v2 判据全部原样复用，本轮只动了编排层。

**代价要照实说**：日频的 `k=3` 是「3 个交易日」，不是「3 周」。所以路径一能回答的是「日频下 1–8 个交易日的领先」，不能与现状的「1–8 周」结论点对点比较；要保留周语义同时用日频数据，必须改 `seg_xcorr`/`ruler._pair` 的裁剪单位（本轮边界不允许）。

**两条路都不必先走**：路径二不产生新信息，只是把否定结论写诚实（`≥0.40` / `≥0.28`），它应当是任何一条路落地后必须附上的那句话，而不是一条独立路线；路径三单独走到不了 `0.2`——`267` 周验证段的 80% 线是 `0.283`，而要在周频上把线压到 `0.20`，按 `neff_far ∝ n` 需要约 `450` 周，超过现有的全部跨度（400 周），训练段将不复存在。`1:2` 相对 `1:1` 在验证段上没有改进（`0.283` 与 `0.270` 的差在 `±0.03` 噪声内），却让训练线从 `0.28` 升到 `0.34`，**不划算**。

**不要把结论写成「当前命题不可判」**：准确的写法是——**周频下 `0.2` 不可判；日频下勉强可判（`r80 = 0.21`）**。若要求「稳定可判」，需要把路径一与路径三叠加（日频 + 267 周验证段 ≈ 1335 个交易日）；按 `neff_far ∝ n` 粗推 `r80 ≈ 0.17–0.18`，这是**推断级（C 级）预测，未实跑**，不能作为排期依据。

### 8.6 局限（必须与数字一起读）

- 日频只跑了验证段：训练段 `1480` 行单任务约 `98s`，且日频任务受内存带宽制约（并行仅约 `1.8` 倍加速），本轮未跑；因此表中日频行没有训练段的对应值。
- 日频 `8` 次重复，`80%` 处的二项标准误约 `±14` 个百分点，`r80 = 0.21` 的真实位置约在 `0.17–0.25` 之间；这个宽度足以判「进入了 `0.2` 量级」，不足以判「精确到 `0.02`」。
- 重排切分用 `20` 次重复（`±8.9` 个百分点），`1:1` 与 `1:2` 的验证线之差在噪声内；`1:2 验证` 的 `r=0.10` 一格为 `35%`、`r=0.15` 一格为 `20%`（非单调），属低端抖动。
- 注入式模拟的近似性质见 §7.5，本 § 不改其边界。
- 数值落点：`paths_summary.json`（入库）；逐次重复原始记录 `paths_raw_daily.jsonl` / `paths_raw_weekly.jsonl` 与第三方原始数据**不入库、仅本地留存**，不作为对外证据。

## 9. 日频直接测法：固定真值下的检出率

### 9.1 为什么不再找交点

§8 的日频 `r80 = 0.21` 是 8 次重复、`±14` 个百分点曲线线性内插的产物，而下一批要判的恰是 `0.21` 与 `0.20` 谁大——在那个精度下这条曲线给不出答案。本节改为不找交点、直接固定真值 `r`，数「200 次里检出几次」。

### 9.2 口径

- **固定真值 + 独立重复**：每格 200 次重复；每次独立取领先块起点、独立取噪声的圆周远平移量（`run_power._one_block` 的随机化部分），与 §7 修正后的实现一致。
- **同一把尺子**：`ruler.measure`（52 点滚动 z → 段内配对 → 窗口峰值 → 循环平移零分布 → 块自助区间），判定 v2 每段 `2.5%`；主口径远平移，严格双版（全+远同时 `≤2.5%`）并列。
- **区间**：Wilson 95%（200 次重复下比正态近似稳）。
- **日频行数语义**：`k0 = 3` 行、`WARM = 52` 行、`far_min = 26` 行（见 `paths_design.md` §2.1）。
- **段长**：验证段 `520` / `780` 交易日，训练段 `1480` 交易日。

|---|---|---|---|---|---|---|---|---|---|

### 9.4 判读（按跑前写死的规则）

规则原文：`r=0.20 / 520 日` 的 95% 区间下限 `<0.60` → 「0.2 量级在 2 年验证段上不可判」，下一批必须用 3 年；下限达到 `0.75` → 2 年够用；中间地带按「需 3 年」处理。

实测下限 `81.6%` ≥ `75%`：

**2 年（520 个交易日）够用。**

### 9.5 斜率与「够用 / 不够用」

- **520 段**：`0.20 → 0.25` 只从 `87.0%` 升到 `91.0%`（`+4` 个百分点），两条 Wilson 区间大幅重叠 → 曲线在 `0.20` 附近已经偏平。
- **780 段对 520 段**：`0.20` 的 `88.0%` 比 `87.0%` 只高 `1` 个百分点，而 `neff_far` 从 `72.1` 涨到 `105.1`（`+46%`）——多攒一年几乎没有换来检出率，增益主要在 `520` 之前已经吃到。
- 合起来读：`0.20` 属于**「够用但不宽裕」**。过线有余（下限 `81.6%` 远高于 `60%` 的不够线、也高于 `75%`），但离「稳」还有距离——要到 `0.25` 才 `91%`。
- 由此 **§8.3 / §8.5 的 `r80 = 0.21` 不再作为下一批输入**：它是 8 次重复曲线内插的读数（真实位置约 `0.17–0.25`），而直接测法在 `0.20` 处已有 `87%`。两法不矛盾，但直接测法精度高，下一批以本节为准。
- 另需注明：`paths_summary.json` 的 `direct.thresholds.valid520.r80 = 0.20` 是「两点网格无法内插、函数返回首个已达到 80% 的网格点」的语义，**不是「0.20 的阈值」**，不得作为阈值引用；`direct` 块只提供逐格检出率。

### 9.6 日频训练段量级

- `r = 0.15 / 1480 交易日` = `80.0%`（`71.1 … 86.7`，100 次重复）→ 训练段 80% 检出线落在 **`0.15` 量级**（实测正好压在 80%，故阈值为 `0.15` 或略低）。
- 对表周频训练段 `0.28`（§7.3，296 周）：日频训练段的检出线约为其一半。
- 只跑了 `0.15` 一点，**不能**内插出 50% 线，也不外推整条曲线；要报训练段 50% 线需再补 `0.10` / `0.12` 两点（未跑，登记为可续跑）。

### 9.7 口径声明（下一批预注册必须照此重写）

**日频的 `k` 是交易日，不是周。** 下列三项在下一批预注册里必须按交易日重写，**不能与现状「1–8 周」直接对读**：

1. **滞后窗**：`1..8` 的单位是交易日（现状为周）；
2. **滚动 z 窗口**：`52` 点是 52 个交易日（约 2.4 个月），现状的 52 周约 1 年——两处不是同一个日历跨度；
3. **先验带**：周频 `k∈[2,6]` 指 2–6 周；日频同数值即 2–6 个交易日，需要重新论证。

本节与 §8 的全部日频数字都按「观测行数」语义产出，不是周语义的日历等价。

### 9.8 未跑格与重复数偏差（必须与表一起读）

- **`r = 0.25 / 780 交易日` 未跑**：仅有 4 次残留，Wilson 区间 `30.1 … 95.4`，等于没测，故表中不列数值。原始记录在 `paths_raw_direct.jsonl`，按 `(r, tag, rep)` 可续跑，已完成的 604 条不会重算。
- **训练段 `r = 0.15` 跑 100 次而非 200 次**：单任务 1480 行约 `140s`、同机有效并行约 `2` 核，200 次约需 `3.9h`。100 次的 Wilson 区间宽约 `±8` 个百分点，足以判「训练段在 `0.15` 量级」，不足以判精确阈值；同一 raw 文件可续跑到 200 次。
- **训练段只跑 `0.15` 一点**（未跑 `0.20` / `0.25` / `0.30`）：`0.15` 已压线 80%，更高 `r` 只会更高，对「量级」判断没有增量，故不做——这是范围取舍，不是能力否定。
- 验证段 `r = 0.20` 两段长都跑满 200 次、`r = 0.25 / 520` 跑满 200 次，即判读所需的三格没有缩样本。
