# 事件时间线 · 「什么算一个事件」判定表

> 创建日：2026-11-08 ｜ 依据代际：壳前置能力（phase0/timeline） ｜ 最后实质修订：2026-11-08
> 本文件是「算不算事件」的唯一 owner；`schema.md` 只管字段，不管定义，遇冲突以本文件为准。
> 本表在抽取任何新样本**之前**写定；写入时刻与 SHA256 记在 `benchmark.md` §6.6 的预注册块里。

## 1. 定义（一句）

一条条目算「事件」，当且仅当它同时满足：**有一个可指认的主体、一个可观察的状态改变、一个可定位的时刻，且它不是提问/建议/综述/分析**。

这四件事都能在标题与摘要的**原文**里被机械检查到，不依赖读者对"重要不重要"的直觉。

## 2. 四条判据

| 代号 | 判据 | 机械检查方式（照做即可） | 不通过时 |
|---|---|---|---|
| **S** 主体可指认 | 原文中有至少一个具名承担者（机构/公司/药物/项目/文书编号），且其名称在标题或摘要里**逐字出现** | 把候选名称当字面串在原文里查找；命中即通过。与 `schema.md` §6 的 `subject_not_in_text` 同一判据 | 不算（`unparsed_subject`） |
| **A** 动作可观测 | 满足 A1 或 A2 任一 | A1：文本里有动作表达（动词或动词性短语），其发生会让主体**进入或退出**一个可登记/受监管/可交易/可任免的状态（启动、停止、批准、拒绝、发布、登记、并购、融资、任免、规则生效）。<br>A2：文本里没有动作动词，但给出了**发布载体线索**——期刊名、`published in`、DOI、预印本库名、官方发布页域名——且条目 URL 指向该载体 | 不算（无状态改变且无发布载体）→ 见 §3 第 3 步 |
| **T** 时点可定位 | 条目自带源发布日期，可解析，且落在评测窗口内 | 取源发布时间（不采信模型自报的日期），按 `parse_date` 解析后与窗口比较 | 判不了（`missing_time` / `out_of_window`），单列 |
| **N** 非评论/非解释 | 文本不是提问、建议、方法学、综述、科普、观点 | ①标题含 `?` 且摘要未补入任何新的状态改变事实；②标题以 `How to` / `Why` / `What` / `Should` / `Key questions` / `Steps to` / `Opinion` / `Commentary` / `Explainer` / `Review of` 等结构性标记开头，且全文没有具名主体的状态改变 | 不算（`not_an_event`） |

A1 的判断点不是"有没有某个词"，而是"能不能指认出一件让外部第三方看得见的状态改变"；词表只作示例，不作判据。

## 3. 判定流程（三步，不同的人照做应得同一结论）

1. **先判 N**：标题/摘要是提问、建议、方法学、综述、科普或观点 → **不算**，结束。
2. **再判 S**：找不到具名的承担者（或承担者只在标题的名词短语里作为研究对象，不是动作发出者）→ **不算**，结束。
3. **再判 A**：有状态改变（A1）或有发布载体线索（A2）→ **算**；两者都找不到 → **判不了**（`insufficient_evidence`），结束。
4. （评测层）对"算"的条目再看 **T**：时点不成立 → **判不了**，单列。

三态都是合法输出：`算` / `不算` / `判不了`。**判不了不是"不算"的委婉说法**——它表示"按这张表无法机械判定"，必须单独计数。

## 4. 四类争议项各自落格

| 类别 | 落格 | 机械依据 | 若算，动作 |
|---|---|---|---|
| 论文题（只有研究对象的名词短语，如 `Effects of X on Y`，全文无动作、无载体线索） | **判不了** | S 过、N 过，A 既不成立也未被否证：标题既不证明"已发表"，也不证明"未发表" | — |
| 同上，但摘要或 URL 给出期刊名 / `published in` / DOI / 预印本库 | **算** | A2 成立：发布载体可核 | `publication` |
| 机构声明（如 `MHRA statement on X`） | **算** | A2 成立：statement 是一份被发布的文书，条目 URL 指向发布方官方页 | `policy` |
| 指引文件（如 `New guidance on the conduct of ...`） | **算**（发布方在标题或摘要可指认时）；发布方不可指认 → **不算**（S 不过） | A2 成立：文件已发布，官方页面可打开核验 | `policy` |
| 监管要求条款（如 `FDA urges sponsors to report ...`） | **算** | A1 成立：监管机构以官方身份发出要求，改变被监管方的公开义务 | `policy` |

车同轨：四类都按 §2 判据落格，没有"像这一类就不算"的特例条款。

## 5. 判不了的计分口径（先于抽样写定，不改）

- **主口径**：`判不了` 的条目不计入 recall 与 precision 的分母（两个方向都排除），单独报 `n_undecidable`。
- **备查口径**：`判不了` 按"不算"计（即召回分母含它、精确分母不含它），一并报出。
- 两套都报，不允许只报一套；下限仍用 `benchmark.md` §3 的五个数，**不改**。
