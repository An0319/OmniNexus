## 0. 本稿用途

本稿用于对外证明流程本身：**先锁定、后跑；留出段开跑前封存、只开封一次；改参必须留痕并公开计次；结果不可回溯**。它不承诺命题一定成立；不成立同样是有效产出，不是事故。

## 1. 命题（一句话，锁定）

产业界新登记的临床试验数量（ClinicalTrials.gov，lead sponsor class = `INDUSTRY`，`INTERVENTIONAL`，按 `StudyFirstPostDate` 周度计数）**系统性领先** State Street SPDR S&P Biotech ETF（XBI）的周收益率 **4–13 周**；方向为正：新登记数量上行后，XBI 后续 4–13 周的周收益倾向为正。

> 标的锁定为 XBI 单一标的；指标锁定为「周收益率」单一指标。不得事后换成其他生物科技 ETF，也不得事后加入成交量/成交额。

## 2. 传导逻辑（为什么值得一测）

产业界新登记试验数量是生物科技研发活动的慢变量：新登记增加通常先于管线扩张、临床里程碑与融资叙事，再到生物科技股定价。若该慢变量对 XBI 存在 4–13 周的领先关系，应表现为正相关峰值落在该窗口；若峰值不在窗口、方向为负或效应量落在弱关联带，则本命题不成立。本稿只验证「领先—滞后关联」，不声称因果。

## 3. 数据口径（锁定）

| 项 | 锁定口径 |
|---|---|
| 领先面 | ClinicalTrials.gov API v2，`https://clinicaltrials.gov/api/v2/studies`。 |
| 筛选条件 | `AREA[LeadSponsorClass]INDUSTRY AND AREA[StudyType]INTERVENTIONAL AND AREA[StudyFirstPostDate]RANGE[2016-11-07,2026-10-30]`。 |
| 纳入 | 牵头赞助方类别 = `INDUSTRY`；研究类型 = `INTERVENTIONAL`；以 `StudyFirstPostDate`（首次登记/首次发布日）为准；所有国家、所有阶段、所有招募状态。 |
| 排除 | 观察性研究、扩展访问（expanded access）、非产业界牵头的研究；`StudyFirstPostDate` 缺失的记录。 |
| 「新登记」定义 | 只认 `StudyFirstPostDate`，不认 `StartDate`（试验开始日），不认 `LastUpdatePostDate`（最后更新日）。 |
| 「产业界」定义 | 只认 `LeadSponsorClass = INDUSTRY`；不把「有产业界合作方但牵头方为学术机构」的研究计入。 |
| 计数单位 | 一条 NCT 记录计 1；按自然周（周一至周日）统计首次登记日落入该周的研究数；周标签固定为该周周五。 |
| 取数方式 | 分页读取：`pageSize=1000`，按 `nextPageToken` 翻页；字段至少取 `NCTId`、`StudyFirstPostDate`、`LeadSponsorClass`、`LeadSponsorName`。本地聚合，不逐周发 count 请求。 |
| 滞后面 | Yahoo chart API，符号 `XBI`（State Street SPDR S&P Biotech ETF），日线 `adjclose`；美元；交易所时区 `America/New_York`。 |
| 周收益率 | `r_t = adjclose_t / adjclose_{t-1} - 1`，按周最后一个交易日计算，周标签固定为该周周五；若周五休市，用该周最后一个交易日，标签仍为周五。 |
| 样本窗口 | 日历窗口 `2016-11-07`–`2026-10-30`；首个周标签 `2016-11-11`，末个周标签 `2026-10-30`。与能源 N1 共用同一窗口；虽然 ClinicalTrials 与 XBI 可取到 `2026-11-06`，但为与能源 N1 对齐并只纳入开跑前已发布数据，末日取 `2026-10-30`。 |
| 对齐 | 两面一律按周标签对齐；临床计数周为周一至周日，标签取该周周五。 |
| 标准化 | 两面分别做滚动 52 周 z-score：`z_t = (x_t - mean(x_{t-51..t})) / std(x_{t-51..t})`，`min_periods=26`；只用当期及过去 52 周，不使用未来值。 |
| 缺失处理 | 不插值、不前向填充。`StudyFirstPostDate` 缺失的记录排除并报数；某周无记录时计 0（这是真实的 0，不是缺失）；有效周缺失超过 5% 时停止并记为数据失败，不产生判定。 |
| 指标数量 | 只保留周收益率一个指标；滞后位共 14 个（`k=0..13`）。 |

**为什么不做地区/阶段筛选**：地区与阶段筛选会引入事后子组选择空间；XBI 成份虽以美国上市生物科技公司为主，但产业界临床试验是全球研发活动。本稿固定为「全球、全阶段、全状态」，避免看到结果后再挑子组。地区/阶段子组分析如要做，只能标为事后探索，不得进入判定。

## 5. 判定标准（锁定，跑之前写死）

对 `k = 0..13` 计算 Pearson 相关 `corr(lead_z_t, lag_z_{t+k})`，按周标签配对，pairwise complete；每个 `k` 都打印样本量 `n`。判定只看 `pass_window = [4,13]` 内的最大正相关 `peak_corr` 及其位置 `peak_k`。

| 参数 | 锁定值 | 说明 |
|---|---|---|
| `lag_range` | `[0,13]` | 共 14 个滞后位；`k=0..3` 只打印，不参与通过判定 |
| `pass_window` | `[4,13]` | 用户指定的领先窗口 |
| `pass_corr` | `0.3` | 沿用项目既有判定线；高于既有零分布 p99（9/27 滞后位校准为 0.218–0.248） |
| `noise_band` | `0.19` | 弱关联描述带，不等于通过线 |
| 方向 | 正 | 领先面上行 → 滞后面上行 |
| 指标 | 周收益率 | 只看一个指标，避免多指标挑结果 |
| 多重比较 | 14 滞后 × 1 指标 | `0.3` 为经验性补偿；本稿不重跑零分布，避免开跑前动线 |

**三种结果定义**

| 结果 | 条件 |
|---|---|
| 成立 | `peak_k` 落在 `[4,13]`，`peak_corr >= 0.3`，且为正相关 |
| 灰区 | 峰值在 `[4,13]` 内但 `0.19 <= peak_corr < 0.3`；或峰值在窗口外但 `|peak_corr| >= 0.19` |
| 不成立 | 验证段 `[4,13]` 内最大正相关 `< 0.19`；或验证段 `[4,13]` 内最大相关为负；或验证段成立但留出段未通过 |

**什么算不成立（逐条写死）**

1. 验证段 `[4,13]` 内最大正相关 `< 0.19`。
2. 验证段 `[4,13]` 内最大相关为负。
3. 验证段判为成立，但留出段按同一标准未通过。
4. 数据缺失超过 5%，或口径不可复现，导致无法产出有效配对；记为数据失败，不得写成成立。

> 「不成立」只表示在该样本、该口径、该窗口下未观察到预期方向与效应量；它不是对因果关系的终局否定。统计显著性不作为通过标准，只看效应量与峰值位置。验证段约 104 周，`n≈100` 时 `|corr|>=0.197` 即达常规 5% 显著；判定线 `0.3` 高于此，但仍须报告每个 `k` 的 `n`。

## 6. 训练 / 验证 / 留出的职责与闸门

| 段 | 允许做什么 | 禁止做什么 |
|---|---|---|
| 训练 | 检查数据对齐、缺失、z-score 行为；可算相关做诊断 | 不得根据训练段结果改窗口、阈值、指标、标的、样本切分 |
| 验证 | 第一次正式判定 | 不得因未通过而改参后重跑并选用更好结果 |
| 留出 | 验证成立后开封一次确认 | 不得二次开封；不得用留出段结果反向调参 |

闸门顺序：训练段自检 → 验证段判定 → 仅当验证段「成立」才开封留出段 → 留出段确认。任何一步失败，后续步骤不启动。
