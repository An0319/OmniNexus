## 1. 待验证假设（H1）

**H1**：OpenAlex 中「large language model / inference optimization」主题的学术热度（周度论文计数，经滚动52周 z-score 标准化），**系统性领先**东方财富「光模块」板块的资金面/交易面信号（周收益率、周成交额，同样标准化）**1~4 周**。

## 3. 判定标准（锁定，跑之前写死）

对每个滞后指标（周收益率、周成交额）分别计算交叉相关 corr(lead_z 滞后k周, lag_z)，k ∈ {0..8}：

- **✅ 传导成立**：|corr| 峰值出现在 **k ∈ [1,4]** 且 corr > **+0.3**（正相关，学术热先行、板块随后）
- **❌ 无传导**：全 k 范围 |corr| < **0.15** → 首链逻辑存疑
- **⚠️ 灰区**：其余情形（峰值在 k=0 或 k≥5、或 0.15 ≤ |corr| ≤ 0.3）→ 不通过不否决，登记后评估换链

**统计注意事项**（对应附录A学习进度）：
- 9个滞后位 × 2个指标 = 18次隐式比较，0.3 的判定线是对多重比较的经验性补偿；若进入正式回测阶段，需改用置换检验（permutation test）给出经验 p 值
- 样本 n≈210 个有效周，|corr|≥0.14 即达常规 5% 显著性——**因此"显著"不作为通过标准，只看效应量与峰值位置**（位置错峰即传导逻辑证伪）

## 8. 零假设校准结论与"下一条链"的判定线定价（2026-09-26）

**问题**：两次实验共 5 个指标，max|corr| 全部 < 0.17，但"多大算大"从来没有依据——
因为从未跑过安慰剂链，不知道"两条毫无关系的序列走同一条管线（对齐→滚动z→交叉相关→
在 9 或 27 个滞后位里取最大值）"本身能跑出多大。

**方法**（三种零分布互证，`phase0/null_calibration.py`，seed=20260926，各臂独立种子，N=500/臂）：

| 方法 | 构造 | 作用 |
|---|---|---|
| 旋转置换 | 领先面整体循环平移随机偏移，保持分布与自相关、只破坏跨序列对齐 | 主口径 |
| FFT 相位随机化 | 保持功率谱（=自相关），随机化相位 | 交叉验证 |
| 合成基准 | 白噪声／随机游走 | 解释慢变量为何更易虚高 |

**结果**（合并两条链 4 个指标序列，2000 次抽样）：

| 统计量 | 数值 |
|---|---|
| 零分布中位数 | 0.131 |
| p90 / p95 | 0.183 / 0.188 |
| p99 / 最大值 | 0.218 / **0.248** |
| **越过 0.3（现通过线）的比例** | **0.0%** |
| **越过 0.15（现噪声带）的比例** | **32.5%** |

**我们自己的观测值落在零分布中的百分位**：chain01 周收益率 46%、chain01 周成交额 54%、
chain10 周收益率 42%、chain10 周成交额 92%。
→ 四个峰值里三个**低于随机配对的中位数**；最高者（0.167）也仅在第 92 百分位，
**独立地再次印证了两条链的证伪结论**。

**由此得到的判定线定价（写死在跑之前，供下一条链使用）**：

1. **0.3 对"周收益率"这类收益序列是成立的**：两种零分布的 p99 分别在 0.183~0.248 与
   0.204~0.235，0.3 位于 99 百分位之上。
2. **0.3 对"周成交额"偏松**：随机游走零分布的 p95 达 **0.335~0.341**——即一个纯随机游走
   的领先面，约 5% 的概率凭空虚高到 0.33 以上。**建议成交额的通过线提高到 0.35**，
   或不再把成交额作为独立判定指标（它与收益率高度相关，会放大"看起来有两个指标"的假象）。
3. **0.15 作为"无传导"噪声带不可用**：32.5% 的纯噪声都会超过它。建议改为
   **零分布 p95（≈0.19）**，或直接取消噪声带、改以"低于零分布中位数"表述弱信号。
4. **披露义务**：以上第三条会把 chain01 的判定从"❌ 无传导"改为"⚠️ 灰区"。
   **不回溯、不翻案**——协议第 3 节判定标准一经执行即锁定；本定价只对**尚未运行**的链生效。

**已知局限（如实披露）**：①论文周计数为整数、取值大量重复，旋转零分布在 chain10 上被离散化
（500 次抽样仅约 19 个不同取值，p95=p99=max=0.183），因此旋转法在强重复序列上会**低估**零分布的
上尾，故以相位法为交叉校验；两者 p99 均在 0.20~0.25 区间，结论一致。②三条链的家族错误率按独立性
近似为 0.0%，真实值会因指标间相关性而略高。
